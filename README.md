# aronbrenner.com

Personal academic site. Static HTML and CSS, no build step.

    index.html    all content
    styles.css    all styling
    assets/       portrait, paper figures
    CNAME         custom domain for GitHub Pages

## Local preview

    python3 -m http.server 8777

Then open http://localhost:8777

## Notes

- The "Papers Explained" section is commented out in `index.html`.
  Uncomment that block and its nav link to restore it.
- Paper figures were extracted from the arXiv source packages.
